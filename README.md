# Iphone 15

Cloned version of iPhone 15 official website with advanced animations.

## 🚀 Live Demo
[View Live Project](https://iphone15-eight.vercel.app/)

## 🛠 Tech Stack
React.js, Next.js, Three.js, GSAP, Tailwind CSS

## ✨ Features
- Video animations
- Scroll animations
- Carousel animations
- 3D iPhone model (movable)
- Fully animated scrolling experience
